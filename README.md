# 🌍 TALENOVA Weather Pro 3.5

A futuristic, zero-build weather intelligence web application designed to run directly on **GitHub Pages** with **no backend server and no paid API keys**.

## ✨ Features

- **Interactive 3D Holographic Earth (`Three.js`)**: Realistic procedural satellite globe with cloud cover, weather-responsive 3D FX, orbital rings, drag rotation, zoom, and smooth city targeting.
- **Global Weather & Forecast Radar Tactical Map**: Interactive Web Mercator map with Satellite, Dark, Street, Terrain, and Offline Vector modes, plus precipitation, wind particle streamlines, cloud cover, temperature, pressure isobars, 24-hour playback, and click-to-inspect coordinates.
- **Complete Forecasts & Analytics (`Chart.js`)**: Current weather, 4 atmospheric intelligence cards, 24-hour scrollable forecast, mandatory expandable 7-day forecast, 24-hour temperature curve, 7-day High/Low trend, and air quality (US AQI, PM2.5/PM10, UV).
- **Voice-Enabled AI Weather Assistant**: Works out-of-the-box with no API key, supports Web Speech voice input & output, and optionally connects to a local Ollama server.
- **Bilingual & Themeable**: Instant English / Japanese (`EN / 日本語`) toggle, `°C / °F` switching, Dark & Light themes, and offline `localStorage` caching.
